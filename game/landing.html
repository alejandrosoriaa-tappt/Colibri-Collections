// Mecánicas

Todo tiene consecuencias.

🤖
Narración por IA

Claude actúa como Game Master, generando escenas cinematográficas únicas en español mexicano. Cada partida es diferente.

📊
5 Estadísticas

Dinero, Salud, Reputación, Nivel de Búsqueda y Vehículo. Todo interconectado. Un error baja la salud; la salud en cero es game over.

🕐
Ciclo Día/Noche

El tiempo avanza con tus acciones. La noche trae más riesgo y mejor pago. La madrugada baja el nivel de búsqueda policial.

🎭
Reputación dinámica

De Desconocido a Leyenda. Tu nivel de respeto abre —y cierra— puertas con facciones: narcos, policías, empresarios y el barrio.

💻
Web + Terminal

Juega en el navegador con interfaz GTA o directamente en tu terminal con colores ANSI y efecto typewriter.

🔓
Open Source

Código abierto en GitHub. Personaliza el mundo, agrega zonas, cambia la narrativa, o usa tu propio modelo de IA.

// Instalación

Empieza en
3 pasos.

# 1. Clona el repo
$ git clone https://github.com/alejandrosoriaa-tappt/Colibri-Collections
$ cd Colibri-Collections/game

# 2. Configura tu API key de Anthropic
$ cp .env.example .env
$ nano .env # agrega ANTHROPIC_API_KEY

# 3. Juega
$ npm install && npm run dev # Web
$ node cli.js # Terminal

// Mecánicas

Todo tiene consecuencias.

🤖
Claude como Game Master

IA genera narración cinematográfica en español mexicano informal. Cada turno es único — no hay dos partidas iguales.

📊
5 Estadísticas vivas

Dinero, Salud, Reputación, Nivel de Búsqueda y Vehículo. Todo interconectado — un error baja la salud y la salud en 0 es game over.

🌙
Ciclo Día/Noche

El tiempo avanza con tus acciones. La noche trae más riesgo y mejor pago. La madrugada baja el nivel de búsqueda policial.

👑
Reputación dinámica

De Desconocido a Leyenda. Tu nivel abre y cierra puertas con narcos, policías, empresarios y el barrio.

💻
Web + Terminal

Interfaz React con UI oscura estilo GTA, o juega directo en tu terminal con colores ANSI y efecto typewriter.

🔓
Open Source

Código abierto en GitHub. Personaliza el mundo, agrega zonas, cambia el tono de la IA o usa tu propio modelo.

// Instalación

Empieza en 3 pasos.

Necesitas Node.js y una API key de Anthropic (gratis para empezar).

# 1. Clona el repo
$ git clone https://github.com/alejandrosoriaa-tappt/Colibri-Collections
$ cd Colibri-Collections/game

# 2. Configura tu API key
$ cp .env.example .env
$ echo "ANTHROPIC_API_KEY=sk-ant-..." >> .env

# 3. Juega
$ npm install && npm run dev # Versión web
$ node cli.js # Versión terminal
